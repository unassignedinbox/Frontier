★ The one you described — all four editors in a single UI

MAIN FIND · PREBUILT · NO BUILD NEEDED Project-Zero — Editor ↗ One editor UI containing the Fracture card, Gas/Fluid (smoke) editor, Wind editor and Particle editor. UI-only by design (“no engine connection”) — its viewport is a checker preview, which is why fracture looks like it has no render here. Exhibits/ProjectZeroEditor/index.html

How to actually see each editor inside Project-Zero

  1. Fracture: in the outliner select a geometry object (Cube / Sphere / Cylinder / Cone) → inspector → Fracture card → switch on Enable fracture → click the ↗ button (top-right of the card; it stays disabled until fracture is enabled). That opens the standalone Fracture Editor, which does have the three.js render.
  2. Fluid / smoke-gas: select Gas Domain → Open FluidEditor (drawer loads the built Fluid app).
  3. Particle: select Flame Source (the emitter child of Gas Domain) → Open ParticleEditor.
  4. Wind: select World → Wind → Wind inspector.

That hidden-until-enabled ↗ is most likely why you “don’t see it”: the Fracture card only shows a diagram glyph — the render lives on the separate Fracture page it opens.

New here — layered procedural material authoring

NEW · SUBSTRATE-STYLE SLABS · CARDS ONLY Material Layer Stack ↗ A cards-only slab editor matching Project-Zero's UI language. Stack an outer coat, metallic colour film and base substrate — or transmission, subsurface, sheen, thin-film and emission — with XYZ IOR/extinction/F0, normal + micro-normal vectors, thickness, Beer attenuation and procedural noise, flakes, weave, checker and Voronoi routed into coverage, colour, roughness, normal and thickness. Live composite sphere/swatches, cost/readouts, warnings, presets and JSON import/export are built in. Exhibits/MaterialLayerStack/index.html

Reference only (native C++, not browser-runnable)

The same panels were also ported to native C++ in Frontier-. The 16 editor-surface headers are copied to Exhibits/NativeSurfaces/ for reference (FractureEditorSurface.h, FluidEditorSurface.h, WindEditorSurface.h, GasCardSurface.h, …) — they need the full native Vulkan/Win32 build to run, so they can’t be served here. Screenshot evidence from the browser fracture editor is in Exhibits/FractureEditor/Captures/. Details: FOUND.md · Exhibits/README.md.

Everything lives under Exhibits/ and is served from this repo’s root — sibling layout is load-bearing: Project-Zero opens ../FractureEditor/index.html, ../Fluid/dist/index.html and ../ParticleEditor/index.html. Don’t move one folder without the others. Rebuild/serve instructions: FOUND.md.
