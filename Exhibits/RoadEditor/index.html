Road Editor · spline routes for Frontier Terrain Lab

Tools

V Select — drag points, Alt+click a segment to insert, double-click to extend the nearest end.

D Draw — click to append points to the active road. Click near the first point to close the loop. Enter finishes.

Space+drag or middle-drag pans in any tool. Wheel zooms to the cursor. F fits all.

Drag an endpoint onto another endpoint to weld a junction; both roads then share that node.

Edit

Del delete point · Shift+Del delete road · Ctrl+Z/Ctrl+Shift+Z undo/redo.

1 2 3 switch Plan / Split / 3D. Ctrl+S downloads the project JSON.

Heights are per-point metres (Y-up). Use Drape to terrain after importing a heightmap, or set Conform → Drape so the ribbon itself hugs the ground.

Exports

.road.json — versioned project, reloadable here and readable by the engine snippet in integration/.

.obj — Y-up metre mesh with the same header convention as Terrain Lab exports. Geometry only.

.csv — centreline stations (s, x, y, z, heading, grade, radius). .png — plan or 3D capture.

Y-up · metres · validation: tight curves (<15 m warn, <7 m error), grades (>8% warn, >12% error), crossings & duplicates.
