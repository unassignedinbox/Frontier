# 🧩 DraftingWorkspace — UI parity checklist against the SolidArc browser editor

**TL;DR**: 58 rows, scored against the SolidArc browser editor (`Experimental/SolidArc/WORKFLOW.md`: browser workflow, all-view grids, upright navigation, Interactive Bevel · B, face extrusion · E, shortcuts / multiselection) and its theme (`Experimental/SolidArc/src/WorkspacePanel.css`).
- **Keymap: Plasticity** (decided 2026-10-20). The 3 open deviations (Ctrl+A, E immediate, no Alt-LMB) now follow Plasticity; § Plasticity keymap maps every default Plasticity key.
- **🟢 51 at parity.** 42 of them are driven by real ImGui input in the three walkthrough scripts (158 expectations) or by a viewport gate; the other 9 are visible in the captures or present in source only (see the Evidence column).
- **⚠️ 1 deviation:** the GLFW host is compile-only here. **🚧 6 not built yet:** sketch drawing, sketch keys, sketch-corner bevel, workplane offset, Outliner multiselection, multi-document.
- Every capture is a real Vulkan frame (SwiftShader Device (Subzero) · Vulkan 1.3.0). It is **not** evidence of physical-GPU performance or desktop window input.

Evidence key: **S** = asserted by a walkthrough script line (`Main` = `WorkspaceWalkthrough.txt`, `Short` = `ShortcutWalkthrough.txt`, `Rec` = `RecoveryWalkthrough.txt`); **V** = viewport gate (V1–V7); **W** = document gate (W1–W8); **C** = visible in the named capture; **Src** = present in source, not driven by a script. Captures are in `Exhibits/DraftingWorkspace/Walkthrough/`; † frames are regenerated by the README commands but not committed (their JSON snapshots are).
