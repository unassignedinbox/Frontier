# 🧩 DraftingWorkspace — UI parity checklist against the SolidArc browser editor

**TL;DR**: 66 rows, scored against the SolidArc browser editor (`Experimental/SolidArc/WORKFLOW.md`: browser workflow, all-view grids, upright navigation, Interactive Bevel · B, face extrusion · E, shortcuts / multiselection) and its theme (`Experimental/SolidArc/src/WorkspacePanel.css`).
- **Keymap: Plasticity** (decided 2026-10-20). The 3 open deviations (Ctrl+A, E immediate, no Alt-LMB) now follow Plasticity; § Plasticity keymap maps every default Plasticity key.
- **🟢 62 at parity** (53 + box selection and image planes from the blueprint study + engineering matcaps + multi-body Outliner multiselection + split bodies / panels (C · X) + curve trim (T) + the editing keys G / R / S · Shift+D · Ctrl+C / V · H family · J / O / P + sketch constraints (K) + spline / reference / linked constraints; `TrimSplitWalkthrough.txt` adds 54 expectations, `EditingWalkthrough.txt` 76, `ConstraintsWalkthrough.txt` 75, `LinkedConstraintsWalkthrough.txt` 55). 44 of them are driven by real ImGui input in the six walkthrough scripts (306 expectations) or by a viewport gate; the other 9 are visible in the captures or present in source only (see the Evidence column).
- **⚠️ 1 deviation:** the GLFW host is compile-only here. **🚧 3 not built yet:** sketch-corner bevel, workplane offset, multi-document.
- Every capture is a real Vulkan frame (SwiftShader Device (Subzero) · Vulkan 1.3.0). It is **not** evidence of physical-GPU performance or desktop window input.

Evidence key: **S** = asserted by a walkthrough script line (`Main` = `WorkspaceWalkthrough.txt`, `Short` = `ShortcutWalkthrough.txt`, `Rec` = `RecoveryWalkthrough.txt`, `Var` = `VariableBlendWalkthrough.txt`, `Sketch` = `SketchDrawingWalkthrough.txt`, `Veh` = `VehicleSurfacingWalkthrough.txt`, `Panel` = `PanelAssemblyWalkthrough.txt`, `Eval` = `SurfaceEvaluationWalkthrough.txt`, `Matcap` = `MatcapWalkthrough.txt`, `Multi` = `MultiBodyWalkthrough.txt`, `Trim` = `TrimSplitWalkthrough.txt`, `Edit` = `EditingWalkthrough.txt`, `Constrain` = `ConstraintsWalkthrough.txt`, `Linked` = `LinkedConstraintsWalkthrough.txt`); **V** = viewport gate (V1–V8); **W** = document gate (W1–W28); **C** = visible in the named capture; **Src** = present in source, not driven by a script. Captures are in `Exhibits/DraftingWorkspace/Walkthrough/`; † frames are regenerated by the README commands but not committed (their JSON snapshots are).
