# Frontier

## Vehicle HMI prototype (combined renderer build)

The combined app — RTX ReSTIR GI path tracer, ray-traced reflections, two-stage screen traces, two clustered-light
systems with point/spot/IES lights, and XPBD, 3D FEM and spring tyre models — lives in
`Experimental/VehicleHmiPrototype`. See its README for the feature map, how to run and test it, and its limits.
